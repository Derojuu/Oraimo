# oraimo Store

Production-ready Next.js App Router conversion of the supplied oraimo main and checkout pages.

## Stack

- Next.js (App Router)
- React
- TypeScript
- Tailwind CSS
- pnpm

## Getting started

```bash
pnpm install
pnpm dev
```

## Production build

```bash
pnpm build
pnpm start
```

The main page is served at `/` and the linked checkout page is served at `/checkout`.
